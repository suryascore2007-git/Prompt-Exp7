# Aim:
To develop a prompt-based application using ChatGPT to demonstrate how to create a prompt-based application to organize daily tasks, showing the progression from simple to more advanced prompt designs and their corresponding outputs.

# AI Tools Required:
- ChatGPT
- Large Language Model (LLM)
- Web Browser
- Text Editor

# Explanation:

A prompt-based application uses carefully designed natural-language prompts to interact with a Large Language Model (LLM). The prompt provides instructions, context, and constraints to guide the AI toward generating the desired output.

In this experiment, a Personal Productivity Assistant is developed using ChatGPT. The assistant is designed to manage daily tasks, schedule reminders, suggest wellness tips, and answer general queries.

The prompt is progressively improved from a simple prompt to a more advanced prompt by adding role, context, instructions, constraints, and expected output format.

# Prompt:

"Design a personal productivity assistant that can help manage daily tasks, schedule reminders, suggest wellness tips, and answer general queries. The assistant should interact using natural language and be adaptable to the user’s changing preferences over time."

# Procedure:

1. Define the core requirements of a personal productivity assistant.

2. Identify and construct appropriate prompts for each task using an LLM such as ChatGPT.

3. Create a simple prompt and generate the corresponding output.

4. Improve the prompt by adding specific instructions, context, constraints, and output requirements.

5. Generate the output using the improved prompt.

6. Develop an advanced prompt that combines task management, scheduling, wellness suggestions, and general queries.

7. Simulate natural user interaction using different user inputs.

8. Compare the outputs generated by simple, improved, and advanced prompts.

9. Collect user preferences and modify the prompt to produce more personalized responses.

10. Analyze the effectiveness of prompt refinement in improving the generated output.

# Simple Prompt:

"Help me organize my daily tasks."

# Output:

"Sure! Please provide your tasks, deadlines, and priorities. I will help you organize them into a simple daily plan."

# Improved Prompt:

"Act as a personal productivity assistant. Help me organize my daily tasks according to their priority and deadline. Categorize each task as High, Medium, or Low priority and provide the tasks in a clear and structured format."

# Example Input:

"I have an exam tomorrow, a Python assignment due in three days, I need to clean my room today, and I want to exercise for 30 minutes."

# Output:

"Daily Task Plan:

1. High Priority:
- Prepare for tomorrow's exam.

2. Medium Priority:
- Clean the room today.
- Exercise for 30 minutes.

3. Low Priority:
- Complete the Python assignment, which is due in three days.

Suggested Order:
1. Exam preparation
2. Cleaning the room
3. Exercise
4. Python assignment

Daily Summary:
Focus mainly on the exam because it has the nearest deadline."

# Advanced Prompt:

"You are an intelligent personal productivity assistant.

Your responsibilities are:
1. Manage and prioritize daily tasks.
2. Organize tasks according to deadlines.
3. Suggest a practical daily schedule.
4. Identify possible schedule conflicts.
5. Provide short and general wellness suggestions.
6. Answer general productivity-related questions.
7. Adapt your responses when the user provides new preferences.

Rules:
- Use clear headings and bullet points.
- Prioritize urgent tasks.
- Do not invent deadlines or appointments.
- Ask for clarification when important information is missing.
- Keep wellness suggestions practical and general.
- Consider previously stated preferences when they are relevant.

When the user provides tasks, return:
A. Priority list
B. Suggested schedule
C. Pending tasks
D. Productivity tip
E. Wellness suggestion"

# Personal Productivity Assistant Features:

1. Daily Task Manager:
- Accept tasks using natural language.
- Organize tasks based on priority and deadline.
- Provide daily summaries and pending tasks.

2. Smart Scheduler:
- Create a practical schedule based on deadlines.
- Identify possible conflicts between tasks.
- Suggest suitable time slots.

3. Wellness Tips Generator:
- Suggest simple wellness activities.
- Recommend breaks during long study sessions.
- Adapt suggestions based on user preferences.

4. General Query Assistant:
- Answer general productivity-related questions.
- Provide suggestions for time management and organization.

5. Preference Adaptation:
- Consider user preferences provided during the interaction.
- Modify recommendations according to changing requirements.

# Prompt Engineering Techniques Used:

1. Role Prompting:
The AI is assigned the role of a personal productivity assistant.

2. Contextual Prompting:
Relevant information such as tasks, deadlines, and user preferences is provided.

3. Instruction Prompting:
Specific instructions are given regarding how the AI should process the tasks.

4. Constraint-Based Prompting:
The AI is instructed not to invent deadlines or appointments and to ask for clarification when necessary.

5. Structured Output Prompting:
The expected response is divided into priority list, schedule, pending tasks, productivity tip, and wellness suggestion.

# Output Analysis:

The simple prompt produced a general response because it contained very little information.

The improved prompt produced a more relevant response because it specified the role of the AI and the required task organization.

The advanced prompt produced a more structured response because it included:
- Role
- Context
- Instructions
- Constraints
- User preferences
- Expected output format

Therefore, refining the prompt improved the relevance, organization, and usefulness of the generated output.

# Limitations:

- The LLM may misunderstand ambiguous instructions.
- Generated schedules may not always be practically suitable.
- A prompt alone cannot create actual device notifications or reminders.
- Persistent memory requires additional application support.
- AI-generated responses may vary for the same type of input.
